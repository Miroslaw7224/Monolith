  • BUG-GP-001

    Konflikt portów backendu i frontendu (5000 vs 5001)

    gen-podsum-ai
    Objaw: Frontend Vite odrzucał zapytania fetch z błędem Connection Refused.
    Rozwiązanie: Wymuszenie PORT=5000 w server.js oraz dedykowany skrypt start_v2.bat.
    Podobny problem w: tester-ai (konflikt portu atrap 8080) oraz code-sensei (baza wektorowa port 6333).
  • BUG-CS-044

    Wyciek pamięci cache embeddings przy dużej liczbie chunków

    code-sensei
    Objaw: Proces Node przekraczał alokację 1.5 GB podczas batchowego generowania wektorów.
    Rozwiązanie: Wprowadzenie LRU Cache z limitem rozmiaru 256 MB i automatycznym czyszczeniem.
    Podobny problem w: english-agent (bufor audio dla lekcji podcastowych).
  • BUG-NX-012

    Cykliczny import między modułem core a schematem rejestru

    nexus
    Objaw: Błąd kompilacji TypeScript podczas generowania typów d.ts dla biblioteki.
    Rozwiązanie: Wydzielenie wspólnych interfejsów do pliku types.d.ts bez kodu wykonywalnego.
    Podobny problem w: second-brain (współdzielone tokeny kart w shell.js).
