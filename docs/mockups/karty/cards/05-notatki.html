Decyzja: rozdzielenie i konfiguracja portów V2 w Gen Podsum AI

W trakcie testów integracji klienta webowego z backendem API wystąpiła kolizja procesów nasłuchujących. Ustalono sztywne rozdzielenie portów: backend API otrzymuje port 5000, natomiast frontend deweloperski Vite działa na porcie 5173, co eliminuje wzajemne blokowanie usług w skryptach startowych.

Kontekst problemu i objawy

  • Domyślna konfiguracja serwera uruchamiała proces na porcie 5001, podczas gdy plik start_v2.bat wymuszał port 5000.
  • Frontend zgłaszał błąd odmowy połączenia z adresem localhost, co blokowało ticket [[GP-001 porty V2]].
  • Brak spójnego przypisania portów utrudniał weryfikację potoku testowego end-to-end.

Podjęta decyzja techniczna

Zamiast dynamicznego wyboru portu w kodzie serwera, przyjęto zasadę jawnej deklaracji w zmiennych środowiskowych oraz przygotowano skrypt łączony:

# start_v2.bat (skrypt uruchomieniowy projektu) start powershell -NoExit -Command "cd server; $env:PORT=5000; npm run start" start powershell -NoExit -Command "cd client; npm run dev"

Powiązane wpisy i konsekwencje

Wdrożenie tej zmiany wymaga zaktualizowania pliku stanu [[Projects/gen-podsum-ai/state.md]] oraz odblokowuje kolejne zadanie w kolejce: [[GP-002 test end-to-end V2]]. Zasada rozdzielania portów deweloperskich została również dodana do notatki ogólnej [[Knowledge/wzorce-agentowe.md]].
